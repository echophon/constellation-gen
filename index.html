In a lane: tall bars are Events, short bars are Ratchet repeats, darker bars with a tail are Burst repeats, hollow bars were blocked by Chance. Dashed outlines show where the Events sat before Rotate. The bracket marks each loop start; numbered cells underneath are steps, wider when divided.

Voices

Each voice follows its Channel's gate. Sustain is the level held while the gate is open, so Width and Flop are heard as note length; set it to 0 for a plain hit.
